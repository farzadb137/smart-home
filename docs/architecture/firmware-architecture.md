1. Why should Wi-Fi, MQTT, and sensor logic be separate components?
Every smart device from now on will use wifi connection and MQTT for connectivity and sending data so having seperate components for wifi and MQTT will save coding time and it just needs developing sensor logic itself and nothing more.
2. What are the advantages of reusable components?
There is no need to rewriting them and can reuse anytime they needed.
3. Why is Git useful in an embedded project?
Using Git will make an opportunity to have several snapshots of project development path so if there was a mistake in this passage we can comeback to safe version of code and rethink the way ahead.
